<h2>How to Download This Template</h2>

<p>
  To download this Unity template, click the green <strong>Code</strong> button near the top of this GitHub page, then select <strong>Download ZIP</strong>.
</p>

<p>After the ZIP file downloads:</p>

<ol>
  <li>Extract/unzip the folder.</li>
  <li>Open <strong>Unity Hub</strong>.</li>
  <li>Click <strong>Add</strong> or <strong>Add project from disk</strong>.</li>
  <li>Select the extracted project folder.</li>
  <li>Open the project using the Unity version listed for the course.</li>
</ol>

<p>
  <strong>Do not open the project directly from inside the ZIP file.</strong>
  The folder must be fully extracted first.
</p>

<p>
  Once the project opens, duplicate the starter scene before making changes.
  Do not edit the master template scene directly.
</p>
